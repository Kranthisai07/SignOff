## Rules (V)
- **Public repository** required.
- Max team size 4; solo allowed.
- **Demo must show only what was built during the hackathon.** Judges must be able to identify original work; failure means immediate disqualification.
- **New work only** (startups may build on existing products; Indie must not). SourceMind code must not be used.
- Disqualified: legal/ethical/platform violations, code/data/assets you don't have rights to.
- Must incorporate Meta's models: Muse Spark series, Muse Wonder, Muse Image, Muse Voice Transcribe, SAM 3.1 (via Meta Model API); open-weight Muse Glimmer and Muse Spark Open (self-hosted or partner); Muse Code agent for coding.
- Submission requires a **3-minute demo video**, which judges use as a primary artifact along with code and live product. Check: repo public, video link opens logged-out, every contributor listed.
- **Anti-projects** (avoid): AI medical advice, basic RAG apps, simple image analyzers, simple education chatbots, job application screeners, nutrition coaches, personality analyzers, sports analyzers/coaches, anything political or war-related.

## Judging (V)
- **Stage 1 (pass/fail):** reasonably fits a theme AND reasonably used Meta Model API and/or Meta open-weight models.
- **Stage 2 (0-10 each):** Impact 30%, Use of Meta AI tooling 25%, Demo 25%, Technical Depth & Execution 20%.
- **Stage 3:** top 5 per track; live final judges watch the demo videos and rank with the same rubric.
